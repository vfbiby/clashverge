# GLOSSARY — claudeguard 产品域

claudeguard 是"对 Claude/Anthropic 出网做管控"的产品域。本文定义该域的规范语言；实施细节一律不进这里（在 02-SPEC 与 experiments）。

## Language

**封禁库 (Blocklist)**:
需要管控的 Claude/Anthropic 系域名与遥测域名的持续维护清单。
_Avoid_: 黑名单、"病毒库"（后者仅作对外营销比喻）

**域名平面**:
以域名（DNS 查询、TLS SNI）识别目标的判定层。
_Avoid_: DNS 层（不完整——SNI 也属此平面）

**地址平面**:
以 IP 识别目标的内核封堵层。
_Avoid_: 防火墙层（歧义——产品整体对外也称防火墙）

**专属出口 (Dedicated Exit)**:
claude 系流量唯一合法的外发通道，只承载封禁库域名。
_Avoid_: 代理（歧义——用户的梯子也叫代理）、内置代理

**看门进程 (Watchdog)**:
常驻守护进程，负责探活、状态机与各组件自愈。
_Avoid_: 守护进程（通用词，AI 场景有歧义）、服务（Windows 语）

**通路 (Path)**:
从本机经专属出口到 Claude 域名的端到端可用性。
_Avoid_: 代理状态、连通性（过宽）

**fail-closed**:
判定不确定时一律按"断"处理的产品原则。

**放行 (Allow)**:
引擎作为发起者替应用重建连接并搬运数据（"代驾"语义），而非防火墙开洞。
_Avoid_: 开白名单、放通

**断 (Kill)**:
令 claude 系连接在 TCP/规则面失败的动作统称；具体实现是 REJECT 注入。
_Avoid_: 封 IP、断网

**REJECT 注入**:
看门策略把专属出口切换为本地拒绝（实测 0.01s 生效）的动作。

**fake-ip**:
裁判发给应用的虚拟地址（位于 198.18.0.0/16），真实目标的映射由引擎内部完成。
_Avoid_: 虚假 IP、假 IP

**白名单模式 (fake-ip whitelist)**:
仅封禁库域名进入 fake-ip 池、其余域名完全不经引擎解析的零侵入模式。

**隧道死 vs 出口拒**:
两类必须分别归因的故障：前者是隧道建立失败（对端 RST/超时），后者是隧道健康但目标边缘拒绝出口 IP。
