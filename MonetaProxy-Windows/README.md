# MonetaProxy Windows 单文件绿色版

一个纯 Go 编写、无黑色 CMD 弹窗、直接驻留 Windows 任务栏右下角托盘的极简代理工具。

- **体积**：仅 **6.6 MB**（单文件绿色版，无任何外部依赖或安装包）
- **核心**：内嵌精简版 Sing-box 核心（仅含 VLESS Reality + AnyTLS）
- **规则**：仅把 **monetamarket.com** 走自建节点，其他网站全部直连

## 功能与右键菜单

运行 `MonetaProxy.exe` 后，任务栏右下角会出现专用小图标，右键菜单支持：

1. **🟢 代理状态**：显示当前连接状态及端口（`127.0.0.1:7891`）。
2. **⏸ 暂停代理 / ▶️ 启用代理**：一键切换 Windows 系统代理（调用 WinINet API，无需重启浏览器秒生效）。
3. **🌐 打开 Moneta 官网**：一键在系统默认浏览器中打开目标网站。
4. **🔄 开机自动启动**：勾选后写入用户启动项，开机静默在托盘运行。
5. **❌ 退出程序**：自动恢复 Windows 系统代理并安全退出后台核心。

## 重新编译

在 Mac 或 Linux 环境下进入该目录，运行：
```bash
./build.sh
```
即可重新生成 `MonetaProxy.exe`。
